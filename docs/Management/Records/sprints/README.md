## Metas de cada Sprint

**Sprint 1 — Base segura y reproducible**

Dejar una base de trabajo segura y reproducible: que cualquier integrante pueda instalar 9Eleven desde cero, que las contraseñas se guarden con hash, que la configuración y la zona horaria sean correctas y que eliminar registros no rompa la aplicación.

**Sprint 2 — CRUD completo y validaciones**

Completar el ciclo de gestión (crear, consultar, editar y eliminar) de productos, categorías y proveedores, con validaciones consistentes y mensajes de error claros.

**Sprint 3 — Ventas y entradas con control de stock**

Registrar ventas y entradas de mercancía actualizando el stock automáticamente, para que el inventario refleje la operación real del minimarket.

**Sprint 4 — Reportes, seguridad y cierre**

Cerrar el proyecto: completar los reportes, endurecer la seguridad, ofrecer recuperación de contraseña y entregar la versión v1.0.0 lista para la aceptación.
